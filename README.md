# Defining ecologically relevant marine heatwave baselines using species specific thermal thresholds 
Scripts for our analyses are in the main folder. Raw data from our experiments are available from Figshare at https://doi.org/10.6084/m9.figshare.33004334. The "Beaty et al. 2023 data and analysis" folder contains some data from Beaty et al. (2023) and the script that we used to investigate whether a fixed experimental temperature threshold (as used in Beaty et al. (2023)) better reflects the thermal threshold of ectotherms compared to seasonally varying thresholds. This was done by investigating how the CTmax and the thermal safety margin change with time (more details in the main paper).
